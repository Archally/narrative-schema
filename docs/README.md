# Narrative format

Start with [the worked deck example](../examples/README.md). Its `narrative.yaml` manifest names the model's plane files. Follow those paths to see how the model records audience intent, claims and evidence, scene order, and delivery.

The [schema directory](../schema/v1.7/) contains the JSON Schema 2020-12 definitions. Use the [root schema](../schema/v1.7/narrative.talk.schema.yaml) for the model manifest and the [metamodel](../schema/v1.7/narrative.metamodel.schema.yaml) for shared definitions.

- [Author and read an untimed outline](2026-11-27-author-a-reading-outline.md) using the Lighthouse Ladder example. Follow event chronology, telling order, entrances, and object possession.
- [Check compatibility with Narrative 1.7](2026-11-27-narrative-1-7-migration.md) for an existing timed model or an untimed outline.

See the [tool commands](../tools/README.md) to check a model locally.
